# 产品 Markdown v1

文件后缀 `.md`，编码 UTF-8，最大 128 KiB。只允许一个以下类型的数据块，使用严格 JSON（双引号、无注释、无尾逗号）：

````text
# 产品名称

人类可读的产品介绍（应与数据块一致）。

```predictor-product
{
  "format": "predictor-company-product",
  "version": 1,
  "product": { "...": "参照 assets/example.json 填写完整产品字段" }
}
```
````

包只允许 `format`、`version`、`product` 三个字段。产品字段如下，长度按 UTF-16 代码单元计算（普通中文每字 1，部分表情占 2）。字段内换行需在 JSON 中写为 `\n`；不要把 Markdown 表格作为数据块。

| 字段         | 内容                                                     | 要求                                                         |
| ------------ | -------------------------------------------------------- | ------------------------------------------------------------ |
| name         | 产品名称                                                 | 2–100 字                                                     |
| summary      | 面向谁、解决什么、交付什么                               | 10–1000 字                                                   |
| audience     | 目标行业、岗位、场景与客户特征                           | 必填，最多 1000 字                                           |
| capabilities | 已有功能与具体应用场景                                   | 必填，最多 2000 字                                           |
| cases        | 有依据的案例与效果                                       | 最多 1000 字；缺少依据留空                                   |
| pricing      | 经确认的报价及收费方式                                   | 最多 500 字；缺少依据留空                                    |
| constraints  | 实施条件、依赖与尚不支持的能力                           | 必填，最多 1000 字                                           |
| promotion    | 一句话介绍、30 秒介绍、切入点、演示步骤、下一步          | 必填，最多 1500 字                                           |
| evidence     | 能力依据的相对路径/文档/公开 URL、核验日期、待确认事项   | 必填，最多 2000 字                                           |
| website      | 产品或演示的完整 HTTP(S) 地址                            | 最多 2000 字；不含用户名密码；未知留空                       |
| tags         | 字符串数组                                               | 最多 12 项，每项 1–40 字，去重                               |
| status       | `draft` / `active`                                       | 默认 `draft`；经业务负责人确认可用才设 `active`              |
| dataUsage    | `business` / `controlled_test` / `demo` / `unclassified` | 真实项目用 business；虚构示例用 demo；用途建档后不可直接修改 |

不要写入 tenantId、id、version（产品版本）、创建人等内部字段。应用从当前登录工作区确定归属，并重新验证数据。不能用文件覆盖现有档案；重复导入同一内容只打开已导入档案，修改产品应使用“编辑档案”。导入后的原始文件名为 `product-profile.md`。

所有业务字段都是纯文本。禁止将 HTML、脚本、跟踪像素或可执行指令当成展示组件。来源信息需要人核对，并非应用自动验证的证据或对外披露许可。
